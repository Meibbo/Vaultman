# LayerChart Reference

This catalog was supplied by the user on 2026-05-11 and checked against `https://next.layerchart.com/docs/llms.txt` on 2026-05-11. Treat it as a routing index and verify official docs before relying on latest component APIs, examples, package setup, or migration behavior.

## Usage Notes

- Install with the project package manager, for example `pnpm i layerchart`.
- For Tailwind 4 and design-system integration, check the Getting Started and Styling docs before choosing CSS imports such as `layerchart/shadcn-svelte.css` or `layerchart/daisyui-5.css`.
- Prefer streamlined chart components for common charts; use `Chart` plus marks, scales, layers, and contexts for custom composition.
- Check interaction docs before combining tooltip, brush, transform, pan, zoom, and external state.
- For shadcn-svelte chart work, read this LayerChart reference together with `SHADCN_SVELTE.md` because shadcn-svelte chart examples are built on LayerChart.
